01 / CONTEXTO

Design não é só
aparência.

Antes de analisar as peças, partimos dos quatro princípios clássicos apresentados nos textos estudados: contraste, repetição, alinhamento e proximidade.

Eles ajudam a organizar a informação, criar hierarquia e estabelecer relações entre os elementos. Quando são ignorados, uma interface pode continuar “funcionando”, mas exigir mais esforço para ser compreendida.

BASE TEÓRICA

Os princípios são tratados como ferramentas para organizar o layout e facilitar a interpretação da mensagem.

PRINCÍPIO SELECIONADO

Contraste

Use diferenças de tamanho, peso, cor, forma ou direção para estabelecer uma hierarquia clara. Contraste não é enfeite: é uma ferramenta de atenção.

01PROXIMIDADEFLIPTRU

QUESTÃO IDENTIFICADA

Quadrinhos grandes demais, grupos pequenos demais.

A organização visual cria uma sensação de aperto entre os quadrinhos, enquanto algumas categorias ficam muito distantes entre si. O resultado é uma página que parece mais longa e fragmentada do que precisa ser.

AntesItens relacionados não têm distância consistente.
DepoisGrupos mais compactos e respiro controlado entre categorias.

QUESTÃO IDENTIFICADA

Título e subtítulo quase encostados.

A relação entre título e subtítulo é correta, mas a distância muito curta faz os dois parecerem um único bloco tipográfico. Reduzir o peso ou o tamanho do subtítulo e ajustar o espaçamento cria uma hierarquia mais confortável.

AntesDois níveis tipográficos visualmente próximos.
DepoisHierarquia preservada com mais respiro.
03ALINHAMENTOPREFEITURA DE FORTALEZA

QUESTÃO IDENTIFICADA

Categorias que parecem escapar do mesmo eixo.

O desalinhamento entre categorias quebra a linha visual que deveria conectar os conteúdos. Mesmo quando os itens pertencem à mesma navegação, seus eixos diferentes tornam a leitura menos previsível.

CONTRASTEQuando tudo quer chamar atenção, nada vira prioridade.

QUESTÃO IDENTIFICADA

Quando tudo grita, nada lidera.

Na peça analisada, cores, títulos, chamadas e elementos promocionais disputam a atenção. A proposta não é retirar personalidade, e sim criar um ponto focal: uma mensagem principal, uma secundária e informações de apoio.

AntesVários focos com peso visual semelhante.
DepoisUm foco principal + níveis de informação.
05REPETIÇÃOSIGAA / SMD

QUESTÃO IDENTIFICADA

A experiência muda de escala entre telas.

Na tela inicial, o conteúdo principal fica concentrado no centro, deixando margens laterais muito grandes. Ao entrar em uma disciplina, a composição passa a ocupar quase toda a largura. Essa mudança enfraquece a sensação de sistema contínuo.

Também observamos o uso de grandes áreas vazias à direita em algumas categorias. O espaço negativo é importante, mas precisa parecer intencional e contribuir para a hierarquia.

✓ repetir a mesma lógica de grid✓ manter escala e margens consistentes✓ usar espaço vazio para separar grupos, não desperdiçar área útil

05 / CONCLUSÃO

Os quatro princípios não são regras para deixar tudo igual.

Eles são ferramentas para decidir o que deve se aproximar, o que deve se destacar, o que deve se alinhar e o que deve se repetir. Ao olhar para interfaces digitais com essas quatro lentes, problemas que antes pareciam apenas “estranhos” passam a ser problemas de comunicação visual que podem ser explicados — e corrigidos.
